使用方式:
  - 在高级设置页选择桌布编号 (1-5)
  - 校准页面实时预览透视矫正后的桌布
  - 辅助线绘制在桌布之上, 球检测在原始帧上运行

纹理特征:
  - 程序生成, 含编织纹路模拟
  - 色差控制在±8以内, 模拟真实布料
  - 适合作为透视矫正后的背景垫层

替换为真实摄影纹理:
  - 拍摄真实台球桌布 (均匀光照, 无球遮挡)
  - 裁剪为512x512正方形
  - 保存为PNG, 覆盖同名文件
  - 重新打包APK
